# Dusk Industries — Make Scenarios

## 1. Dusk Ops — Google Calendar Sync

Purpose:
- read unsynced calendar jobs generated by Dusk Industries
- create the corresponding Google Calendar event
- write the returned Google event ID back to Dusk Industries
- avoid duplicates by only returning jobs that do not yet have a stored Calendar ID

Endpoints:

GET  https://duskdawolf.com/api/integrations/make/calendar-jobs
POST https://duskdawolf.com/api/integrations/make/calendar-jobs

Header:

Authorization: Bearer <MAKE_WEBHOOK_SECRET>

Recommended flow:

Scheduled trigger
→ GET calendar jobs
→ Iterator
→ Google Calendar — Create Event
→ POST receipt with Google event ID

Recommended initial interval: every 15 minutes.

## 2. Dusk Ops — Telegram Notification Router

Purpose:
- read pending Telegram notification deliveries
- send them to Dusk through Telegram
- write the Telegram message ID and delivery status back into Dusk Industries

Endpoints:

GET  https://duskdawolf.com/api/integrations/make/notifications
POST https://duskdawolf.com/api/integrations/make/notifications

Header:

Authorization: Bearer <MAKE_WEBHOOK_SECRET>

Recommended flow:

Scheduled trigger
→ GET pending Telegram deliveries
→ Iterator
→ Telegram Bot — Send Text Message
→ POST delivery receipt

Recommended initial interval: every 5 minutes.
